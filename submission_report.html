1. Executive Summary & Objective

The objective of this assignment was to apply advanced CSS fundamentals to transform an initial semantic HTML personal resume into an executive-level, visually engaging, responsive portfolio website. The site highlights my professional background as an AI FinTech Founder & Product Strategist (Founder & CEO at FinnDot, Ex-CEO at Anomapro — acquired by Watad Group, and IIM Bangalore FinTech alumnus). The enhancements focus on modern visual hierarchy, fluid typography, consistent brand theming, and responsive multi-column layouts using CSS Flexbox and Grid.

2. Key Improvements & CSS Concepts Applied

A. Typography & Readability
Imported Google Fonts (Plus Jakarta Sans for punchy headings and Inter for body copy). Applied fluid font sizing using clamp(), structured line-heights (1.6 for body, 1.25 for headers), and letter spacing to elevate corporate aesthetic.
B. Modern CSS Variables & Color Palette
Defined comprehensive CSS Custom Properties in :root. Established an "Executive Tech" palette: Deep Slate (#0f172a), Brand Royal Blue (#2563eb), Sky Accent (#0ea5e9), and soft slate card surfaces (#ffffff, #f8fafc) ensuring WCAG-compliant contrast.
C. Sticky Navigation & Frosted Glass
Implemented a top sticky navigation bar using position: sticky; top: 0; with backdrop blur (backdrop-filter: blur(12px)), animated hover underlines via ::after pseudo-elements, and responsive mobile hamburger drawer.
D. Flexbox & CSS Grid Layouts
Replaced inline/block flows with modern Flexbox for headers, badge chips, and hero CTA clusters. Implemented CSS Grid with grid-template-columns: repeat(auto-fit, minmax(...)) for responsive 2-column and 3-column card arrangements.

3. Efficient CSS Selector Strategy

  • Element Selectors: Normalized global elements (html, body, h1-h6, p, button, input) with a clean universal box-sizing reset (box-sizing: border-box).
  • Class Selectors: Modular, reusable utility and component classes (e.g., .card, .btn, .btn-primary, .badge-pill, .grid-2, .grid-3) enforcing strict DRY principles.
  • ID Selectors: Targeted major semantic landmark sections (#hero, #about, #ventures, #experience, #skills, #education, #contact) for smooth page jump anchors.
  • Attribute Selectors & Pseudo-States: Styled form controls via input[type="email"], focus rings with :focus, interactive states via :hover and :active, and glowing timeline badges using ::before.

4. Section Architecture & Design Decisions

Hero Section (#hero) — Positioning & Visual Engagement
Features a two-column flex layout pairing an introductory value proposition with a floating interactive Profile Card. Includes a pulsing status indicator badge (CSS @keyframes pulse), a multi-stop gradient avatar circle, and primary/secondary CTA buttons with subtle elevation shadows (box-shadow and transform: translateY(-2px)).
About & Flagship Ventures (#about, #ventures) — Feature Grid & Status Badges
Organized into 3-column CSS Grid cards showcasing key domain pillars (AI FinTech, Fraud Intelligence, 0-to-1 Product Strategy) and flagship ventures (FinnDot, Anomapro M&A exit, Chara EV mobility). Each card utilizes light color-tinted icon containers, dedicated status pills (e.g. .status-acquired in violet), and structured impact highlights.
Experience Timeline (#experience) — Relative & Absolute Positioning
Constructed a chronological timeline connecting career milestones (FinnDot, Watad Group / Anomapro, Chara, Sirma, APPZUI). Utilized a central vertical line created with a CSS pseudo-element ::before, combined with absolutely positioned marker dots that expand and glow on card hover for enhanced interactive feedback.
Skills & Competencies (#skills) — Animated Progress Meters & Cloud Tags
Showcases two core categories (Business Strategy & FinTech Customer Data Intelligence) using customized progress tracks with linear gradient fills. Below, a flex-wrapping tag cloud (.badge-container) displays methodologies with rounded pill borders and smooth interactive hover inversion.
Education & Credentials (#education) — Academic Hierarchy & Certifications
Highlights the Executive FinTech Programme at IIM Bangalore and Bachelor of Engineering at DSCE with gold/blue distinction badges, alongside verified credentials (Google Certified Associate Android Developer, MATLAB Onramp, and published research on Assistive Devices).
Contact Section (#contact) — Interactive Form Controls & Focus States
Dual-column card featuring direct communication channels (Email, LinkedIn, GitHub, Bengaluru location) and a functional contact form. Form inputs employ CSS attribute selectors, custom active focus rings (border-color: var(--border-focus), box-shadow: 0 0 0 3px rgba(37,99,235,0.15)), and clear placeholder styling.

5. Responsive Strategy & GitHub Hosting

Mobile Responsiveness: Built with a mobile-first philosophy using CSS Media Queries (@media (max-width: 992px), @media (max-width: 768px), @media (max-width: 480px)). On mobile displays, navigation seamlessly transitions into a toggleable slide drawer, multi-column grids collapse into comfortable single-column stacks, and touch targets remain well above the 44px minimum for optimal usability.

Hosting & Deployment: The complete source code is maintained in the GitHub repository at https://github.com/devaka207/resume-website and hosted live via GitHub Pages with SSL encryption enabled.
